# 014 動画の終了位置は保存せず、終了位置の操作で尺を変える

日付: 2026-10-14

## 状況
M3 まで動画は「開始位置」だけを持ち、使う長さはタイムラインの尺（均等割りや尺スライダー）で決まっていた。
利用者から「再生の終わりも指定したい。そうしたら尺も連動してほしい」という要望が出た。

## 選択肢
1. `trimEndFrames` をモデルに保存し、尺を `trimEnd − trimStart` から導く
2. 保存するのは開始位置と尺のまま。終了位置は `trimStartFrames + durationFrames` から求め、終了位置を動かしたら尺を「終了位置 − 開始位置」に変える
3. 終了位置を動かしても尺は保ち、使う範囲だけ縮める（足りない分はホールド）

## 決定
2 を採用。`timeline/trim.ts` の `trimEndFrames` / `trimEndRange`、`projectActions.setTrimEnd`。
開始位置を動かしたときは尺を変えない（使う範囲が前後に滑る）。終了位置を動かしたときは開始位置を変えない。

## 理由
- 1 は「尺の合計 = 総尺」の不変条件と二重管理になる。尺の再配分（`adjustDurations`）のたびに終了位置も直す必要があり、
  素材が 1 つのとき（尺が総尺で固定）に終了位置が意味を持たない。
- 3 は「終了位置を変えたら尺が変わってほしい」という要望に合わない。
- 2 なら尺の規則（最小尺、他の素材の最小尺、差分の比例配分）は `setItemDuration` に 1 か所だけあり、終了位置はその別の入り口になる。

## 制約
- 終了位置の上限は元動画の末尾から「トランジションで見える長さが尺より延びる分」を引いた値。引かないと、末尾まで使ったときに
  見える長さが元動画を超え、`clampTrims` が開始位置を手前に戻してしまう。`setTrimEnd` も UI も同じ `trimEndRange` で上限を決める。
- 元動画が見える長さより短いとき（末尾ホールド中）は、終了位置がスライダーの範囲の外になるので動かせない。尺は一覧のスライダーで変える。
