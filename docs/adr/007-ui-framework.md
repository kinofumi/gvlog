# 007 UI は Tailwind CSS + shadcn/ui（暫定）

日付: 2026-10-08

## 状況
スマホのタッチ操作向けにスライダー、ボトムシート、ダイアログが必要。読者は Tailwind 初心者。見た目は後で調整する。

## 選択肢
1. Tailwind CSS v4 + shadcn/ui（Radix UI ベース、コンポーネントをプロジェクト内にコピー）
2. MUI / Mantine
3. CSS Modules のみ

## 決定
1 を暫定採用。配色やフォントは M5 で決め、それまでは既定テーマを使う。

## 理由
必要な部品がそろい、コピー方式なので後からの調整が自由。使った分だけのバンドルで軽い。
MUI / Mantine はデスクトップ寄りで重い。CSS Modules のみだと部品を自作する量が多い。
