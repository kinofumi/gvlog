# 016 白フェード（fadeWhite）を v1 に前倒しする

日付: 2026-11-11

## 状況
plan §0 では fadeWhite / fadeBlack / slide は後の章（M6）としていた。
フィールドテスト後に「全員の動画を集めて順に並べ 1 本にする『つなげる』モード」の要望が出て、
利用者は「つなぐだけだと違和感があるので、短く白フェードアウトして、次の動画を短くフェードインさせてほしい」と指定した。

## 決定
- `Transition.type` に `'fadeWhite'` を足す。区間の扱いは crossfade と同じオーバーラップ方式（ADR 005）で、compile は変えない。
- 描画（`renderFrame`）: 前半（進行度 < 0.5）は前の素材だけ、後半は後の素材だけを不透明で描き、その上に白を
  `1 − |2q − 1|`（始まり 0 → 中央 1 → 終わり 0）の不透明度で重ねる。中央のフレームは真っ白になる。
- 編集画面の「次へのつなぎ」に「白フェード」のチップを足す。長さのスライダーはクロスフェードと共用。
- 「つなげる」モードはこの fadeWhite を既定のつなぎに使う。

## 理由
- つなげるモードの要件そのものなので、後の章に残す理由がなくなった。
- オーバーラップ方式に乗せれば、タイムラインの計算・切り詰め・テストはすべて既存のまま使える。足すのは描画の数行と画素のテスト。
- fadeBlack と slide は今も要望がないので据え置く。

## 影響
- 白フェードの中央では両方の素材が見えないので、短い長さ（既定 0.5 秒）で十分。長いと「白い間」が目立つ。
- プレビューと書き出しは同じ `renderFrame` を使うので見た目は揃う。
