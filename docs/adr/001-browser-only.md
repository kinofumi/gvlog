# 001 ブラウザ完結・サーバーなしで動画を生成する

日付: 2026-10-08

## 状況
グループ Vlog 用に、各メンバーがスマホで短尺素材を作りたい。AI 動画生成 API は従量課金と結果の不確実性が課題。

## 選択肢
1. Gemini / Veo などの生成 API を使う
2. サーバーで ffmpeg レンダリング
3. ブラウザの Canvas + WebCodecs で端末内レンダリング

## 決定
3 を採用。静的サイトとして GitHub Pages に置く。

## 理由
運用費ゼロ、画像を外部に送らない、ログイン不要で URL 共有だけで使える。
10 秒程度の素材ならスマホでも数秒〜数十秒で書き出せる。
