# 023 ホーム画面からはアプリ風の全画面（standalone）で開く

日付: 2026-11-14（022 の「開き方はブラウザのまま」を置き換える）

## 状況

ADR 022 で `display: browser` にしたところ、Android の Chrome が「インストールできません」と表示し、ショートカットの作成しか提案しなかった
（Chrome は display が standalone などでないページをインストール可能とみなさない）。ショートカットでも動きは同じだが、参加者に「使えないのか」と思わせる文言が出る。

## 選択肢

1. `browser` のまま。栞に「ショートカットを作成を選んでください」と案内する
2. `standalone` に変える。Android は「インストール」でき、iPhone もホーム画面から開くとアドレスバーの無い全画面になる
3. `minimal-ui`。Android はインストール可能になるが、iPhone での扱いが版によって違い、確認する手間が増える

## 決定

2 を採る（利用者の判断）。変更は manifest の 1 行だけ。

## 理由

- 「インストールできません」の表示を無くすには display を変えるしかない。
- 022 で standalone を避けた理由は「iPhone の全画面モードで共有・保存の挙動が変わるかもしれない」だったが、これは実機で 1 回通せば確かめられる
  （チェックリスト: ホーム画面から開いて、書き出し → 共有シート → 写真アプリに保存）。
- 外部リンク（Google マップ）は `target="_blank"` なので、全画面モードでもブラウザ側で開く。

## 影響

- iPhone で全画面になると「戻る」や再読み込みの UI が無い。タブで行き来するだけのアプリなので支障は小さい。
- 問題が出たら manifest を `browser` に戻すだけで元に戻る（ホーム画面のアイコンは追加し直しが要る）。
