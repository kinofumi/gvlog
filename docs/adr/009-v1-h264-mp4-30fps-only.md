# 009 v1 は H.264 / MP4 / 30fps のみ。フォールバックしない

日付: 2026-10-08

## 状況
元プランは H.264 が使えない端末で WebM に切り替え、fps も 24 / 60 を許していた。Codex のレビュー（指摘 6・11）で、
MP4 を揃えるという納品要件と矛盾し、教材としても経路が増えすぎると指摘された。

## 選択肢
1. H.264 → VP9 → VP8 の順にフォールバックして必ず何かを出す
2. H.264 / MP4 / 30fps だけに限定し、使えない端末は「非対応」として止める

## 決定
2 を採用。判定は実際の幅・高さ・fps・ビットレートで `canEncodeVideo` に問い合わせる。Worker 化も v1 では行わない。

## 理由
WebM を出しても CapCut に並べられず、仕上げ担当者の手間になる。経路が 1 本なら読者が追いやすく、テストも実機検証も絞れる。
対応表には実機で成功した条件だけを載せる。
