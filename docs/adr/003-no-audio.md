# 003 出力に音声を含めない

日付: 2026-10-08

## 状況
入力動画には音声があることが多い。BGM と読み上げは仕上げ担当者が CapCut / Vrew で付ける。

## 選択肢
1. 元動画の音声を残す
2. 素材ごとに残す・残さないを選べる
3. 音声は含めない（無音 MP4）

## 決定
3 を採用。

## 理由
音声のデコード・ミックス・エンコードが不要になり、実装量が大きく減る。
Safari 16.4〜18 は WebCodecs の音声系を持たないため、無音にすることで iOS の対応範囲も広がる。
仕上げ工程で音は付ける前提なので、素材段階の音声は使われない。
