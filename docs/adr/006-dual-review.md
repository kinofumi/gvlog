# 006 Claude と Codex の二重レビューを行う

日付: 2026-10-08

## 状況
堅牢なコードにしたい。また、複数の AI でレビューする手順を教材にしたい。

## 選択肢
1. Claude のレビューのみ
2. Claude ＋ Codex（別モデル）の二重レビュー
3. 人間レビューのみ

## 決定
2 を採用。Claude の `/code-review` → gstack の `/codex review`（重要モジュールは `/codex challenge` も）→ 人間の判断。
結果は `docs/reviews/` に残す。

## 理由
コードを書いたモデルと別のモデルが見ることで、同じ思い込みを共有しにくい。
Codex は読み取り専用で動くためファイルを壊さない。食い違いの記録が教材として価値を持つ。
レビューはテストの代わりではないので、純粋ロジックはテストファーストを主とする。
