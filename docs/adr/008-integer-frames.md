# 008 内部時間は整数フレームで持ち、素材内時刻の規則を固定する

日付: 2026-10-08

## 状況
Codex のプランレビュー（指摘 2・3）で、秒の浮動小数では 3 等分が割り切れないこと、トランジションで重なる区間の
「素材内の時刻」が未定義であることが指摘された。

## 選択肢
1. 秒（浮動小数）のまま、丸めで対処する
2. 内部はフレーム番号（整数）、秒は UI の表示と入力のときだけ変換する

## 決定
2 を採用。均等割りの端数は先頭から 1 フレームずつ配る。素材が画面に見え始めた瞬間（visibleStart）を素材内の開始点とし、
動画は `sourceFrame = trimStart + (t − visibleStart)`、Ken Burns とキャプションも同じ規則で進める。

## 理由
合計 = 固定尺の不変条件が整数で厳密に成り立ち、テストで検証しやすい。トランジション変更で動画の見える時刻がどう動くかが
仕様として読める。
