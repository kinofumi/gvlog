# 対応表（実機で確認できた条件だけを載せる）

「対応」と書けるのは、このアプリで実際に MP4 を書き出し、保存先と CapCut で確認できた組み合わせだけ。
能力判定（`canEncodeVideo` など）の結果は参考情報で、対応の根拠にはしない。

## 確認のしかた

1. PC で `npm run dev` を起動し、同じ Wi-Fi のスマホから `https://<PC の IP>:5173/groupe-vlog/` を開く
   （自己署名証明書の警告が出るので「詳細」→「このまま開く」）。
2. 名前とスポットを入れ、写真 1 枚と動画 1 本を選び「書き出す」。
3. 完了したら「共有（写真に保存）」→ 写真アプリで再生。
4. 出力ファイルを PC に送り、`scripts/verify-output.sh <ファイル>` で属性と冒頭・中央・末尾のフレームを確認。
5. CapCut に読み込んでタイムラインに置けることを確認。
6. この表に OS バージョン、機種、結果を追記する。
