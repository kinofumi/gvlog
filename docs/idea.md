# **Vlog素材作成・編集自動化ツール 開発仕様書**

本ドキュメントは、グループでのVlog動画制作効率化を目的とした「ブラウザ完結型 Vlog素材作成Webアプリ」のプランおよび仕様をまとめたものです。

## **1\. プロジェクト概要**

Google AI StudioやGemini API（Veo）などのAI動画生成機能は、従量課金コストや生成結果の不確実性が課題となります。本プランでは、静止画に「ケン・バーンズ（Ken Burns）エフェクト（ズーム・パン）」とテロップを合成する処理を、サーバー費用のかからない**完全ブラウザ完結型（クライアントサイド）Webアプリ**として構築・運用します。

## **2\. 全体制作ワークフロー**

| ステップ | 作業内容 | 担当 / 使用ツール |
| :---- | :---- | :---- |
| **Step 1: 事前準備** | 動画の縦横比（16:9 / 9:16）、1スポットあたりの秒数、テロップデザインなどの共通ルールを策定。 | グループ全員 |
| **Step 2: 素材作成** | 自作Webアプリに写真とコメントを入力し、ズーム/パン指定・テロップ合成を行った短尺MP4動画を各自出力。 | 各スポット担当者 （自作Webアプリ） |
| **Step 3: 全体編集** | 各自が書き出したMP4動画素材を1つのフォルダに集約。タイムラインに並べ、BGM・トランジション・自動読み上げ音声を加えて仕上げる。 | 全体仕上げ担当者 （CapCut / Vrew等） |

## **3\. Webアプリ機能仕様**

### **3.1 主な機能要件**

> * **画像アップロード機能:** 各スポットの静止画（JPEG/PNG等）を取り込み。  
> * **エフェクト指定機能:** ケン・バーンズ効果（ズームイン、ズームアウト、左から右へパン、右から左へパンなど）を選択。  
> * **キャプション（テロップ）編集:** 表示文言の入力、表示位置（上部・中央・下部）、表示タイミングおよびフォントスタイルの設定。  
> * **動画描画＆変換処理:** HTML5 CanvasとJavaScript（WebCodecs API等）を用いてアニメーションを描画し、MP4/WebM形式に変換。  
> * **ローカルダウンロード機能:** サーバーを介さず、ユーザーの端末へ生成された動画ファイルを直接保存。

### **3.2 システム構成・技術スタック**

> * **フロントエンド:** HTML5, CSS3, JavaScript (ES6+)  
> * **描画＆エンコードエンジン:** HTML5 Canvas API, WebCodecs API（または webm-muxer / ffmpeg.wasm）  
> * **ホスティング環境:** GitHub Pages / Vercel / Netlify （静的ファイル配信のため完全無料で運用可能）

## **4\. 本プランのメリット**

> 1. **運用コスト完全ゼロ:** サーバー側でレンダリングを行わず、Gemini API等の従量課金も発生しないため、維持費が一切かかりません。  
> 2. **処理速度と確実性:** クラウド処理待ちが発生せず数秒でレンダリングが完了し、意図通りのカメラワークとテロップ配置が確実に再現されます。  
> 3. **高いプライバシー性:** アップロードした画像やテキストが外部サーバーへ送信されないため、安心して利用できます。  
> 4. **簡単なアクセス性:** URLを共有するだけで、グループメンバー全員がログイン不要でPC・スマホから利用可能です。
