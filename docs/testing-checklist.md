## 白フェードとつなげる（ADR 016、017）

- [ ] 編集で「白フェード」を選ぶと、プレビューでも生成した動画でも、境界で一度白くなってから次の素材に変わる
- [ ] 「つなげる」タブで iPhone と Android で生成した MP4 を混ぜて選び、順番を入れ替えて生成できる
- [ ] つなげた動画の長さが「表紙 3 秒 + 各動画の合計 + 終わり約 1 秒」で、境界が白フェードになっている
- [ ] つなげる途中でキャンセルできる。生成中は編集タブの「動画を生成」が押せない
- [x] つなげた動画の先頭に 3 秒の表紙（入力欄の文字）が付き、最後が白くフェードアウトして終わる。文字を空にすると表紙が無い（実機、2026-11-12）
- [x] 「保存・共有」で共有シートを閉じると「保存・共有が完了しました。」のポップアップが出る。キャンセルしたときは出ない（実機、2026-11-12）

- [x] 「つなげる」のプレビューで、表紙の止め絵 → 各動画が順に再生 → 白い終わり、と進み、BGM が鳴る。iPhone で音が出る（操作から始めるため）。タブを離れると止まり、戻っても再開しない（実機、2026-11-12）
- [x] iPhone の低電力モードで「つなげる」のプレビューを再生すると、動く（操作の中で play() を呼んでいるため）か、赤い文で「始められませんでした」と出る（動画が一瞬で飛ばされない）（実機、2026-11-12）

## BGM（ADR 019）

- [x] 「つなげる」の BGM で各曲の試聴（再生ボタン）ができる。iPhone はサイレントスイッチの影響に注意（実機、2026-11-12）
