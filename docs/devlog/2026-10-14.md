## M3(B2) 取り込み UI・トリム UI・プレビューの <video>（同ブランチ）
- `PhotoPicker` を `MediaPicker` に（`image/*,video/*`）。動画は `importVideo` → ポスター（`media/videoPoster.ts`、CanvasSink で先頭フレーム）。
  `TrimEditor`（開始位置、上限 = 元動画の尺 − 見える長さ）。`preview/previewVideos.ts` が素材ごとの `<video>` を持ち、停止中はシーク、再生中は `play()` と再同期。
- 判断: 動画データはメモリ上の Blob にして `BlobSource` と `<video>` の Object URL で共有（ADR 012 に補足）。`<video>` は素材ごとに 1 つ（上限 10 なのでプール管理はしない、plan §3.3）。
- ヘッドレス Chrome で、1 秒ごとに色が変わる 10 秒の動画＋写真で確認: 開始位置 3 秒 → プレビュー 0 秒が黄、再生中 1 秒がマゼンタ、
  書き出しの 0 / 1.5 / 2.5 / 4.9 秒が黄 / マゼンタ / シアン / グレー、5 秒以降は写真の赤。動画が 2 番目のときも一致。削除・再追加でエラーなし。

- 二重レビュー: Codex 3 件（P1: 元動画が短いときの末尾で シークが循環）、Claude 10 件。シークと再生の判断を純粋関数 `planFrame` に切り出してテストファーストで固めた。
  不採用 3 件（シーク中はポスター: ちらつく / `firstTimestampSec` をプレビューにも足す: 原点が違うので逆 / compile の共通化）。記録は `docs/reviews/2026-10-14-m3b2-video-ui.md`。
  213 件通過。回転付き H.264 の MOV はプレビューと書き出しで同じ向き。`main` にマージ。
