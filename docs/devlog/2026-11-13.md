# 2026-11-13

- 起動時の表紙（ADR 021、ブランチ splash）: 利用者の要望「アプリの画面の前にイベントの画像をスプラッシュ的に見せたい」。
  `Splash` コンポーネントを App の上にかぶせ、2 秒たつかタップで 0.3 秒かけて消える。画像は `public/splash.png`（差し替えるだけ）、`index.html` で先読み。
  仮の画像は `scripts/make-splash.mjs`（`@napi-rs/canvas`、devDependency にある）で 1080x1920 の青いグラデーションに文字を描いて作った。
  ヘッドレスで、開いた直後に表示（画像が読めている）、2.26 秒後に消えている、クリックで 0.4 秒以内に消えている、を確認。
  デスクトップ幅で「タップで始める」の文字が画像に重なって読みにくかったので、白の半透明の下地を付けた。
  二重レビュー（`docs/reviews/2026-11-13-splash.md`）: 両方が「onDone を effect の依存に入れるとフェードのタイマーが延びる」「表紙の裏にフォーカスが行く」を指摘。
  ref で最新の onDone を持つ形にし、表紙の間は main を inert に。ほかに、フェード中のタップの吸い込み（pointer-events-none）、画像の長押し（img を pointer-events-none、draggable=false）、
  2 秒は画像が出てから数える、画像が読めなければすぐ消える、を反映。
- 見出しのアイコン（ブランチ ui-title-icon）: 「タイトルが寂しい」との感想で、h1 の文字の前にマークを置いた。マークは public/favicon.svg を描き直したもの（Vite の初期の稲妻から、
  ボタンと同じ blue-700 のビデオカメラに白い再生の三角に変更）で、見出しは `<img>` で同じファイルを使う（差し替えが 1 か所で済む）。見た目だけなので二重レビューは省略し、スクリーンショットで確認。

  `ui/Icon.tsx` に線だけの単純な SVG を 9 種（写真・フィルム・再生・保存・フォルダ・箇条書き・文字・音符・鎖）手で書いた（アイコン集のライブラリは入れない）。
  帯は flex で絵（h-6）と文字を横に並べる。見た目だけなので二重レビューは省略し、編集タブ・つなげるタブのスクリーンショットで確認。h1 のマークはそのまま残した。
