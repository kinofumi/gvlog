  章ごとの HTML（前後の章への行き先と章内の目次つき）、`index.html`（プラン）、`all.html`（全章を 1 ファイル、印刷用）。CSS は `scripts/study-style.css` を埋め込み、画像も外部読み込みも無い 1 ファイルで完結。
- うまくいかなかったこと: pandoc の既定 CSS が body を 36em に絞り、色分けしたコードを `div.sourceCode` で包むので、`body > pre` のような指定では幅がそろわなかった → 本文を `<main>` で包んで main に幅を持たせ、`div.sourceCode` の余白を指定。
  見出し（白抜き）の中のインラインコードが読めない → `h2 code` を半透明の白に。スマホ幅（390px）で 8 章の長いインラインコードが画面を横に伸ばしていた → `:not(pre) > code { overflow-wrap: anywhere }`。コードブロックは横スクロールのまま。
  1 ファイル版の章リンクは pandoc が付ける見出し id に向けた。README の見出しの「—」で id が `--` になるのを見落とし、生成後に id の存在を全部確かめて直した。
