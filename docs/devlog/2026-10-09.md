## 見つかった問題
- 別の試行で `TypeError: network error（avc1.42E028 / quality）`。エンコード設定は診断で成功しているので、エンコーダの失敗ではない。
  Chrome が `Blob.arrayBuffer()` でファイルを読めなかったときの文言で、書き出し中に読むのは動画ファイルだけなので、
  選択した動画が書き出し時点で読めなくなっていたと推定。Android の File はアプリ切り替えや時間経過で読めなくなることがある。
- 人間の判断: 取り込み時に動画をまるごとメモリへ読み込む（ADR 012）。`BlobSource` → `BufferSource`、上限 500 MB → 200 MB、
  読めなければ取り込み時点で「選び直してください」。
