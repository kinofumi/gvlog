# レビュー: 起動時の表紙（スプラッシュ、ADR 021）

日付: 2026-11-13 / ブランチ: splash / 対象: ステージ済みの差分（Splash.tsx 新規、App.tsx、index.html、public/splash.png、docs）

## Claude `/code-review medium`（7 件）

1. Splash.tsx:35 — フェード中（透明）も button が画面を覆いタップを吸い込む。motion-reduce では見えない板が 300ms 残る。→ **反映**: fading のとき `pointer-events-none`。
2. Splash.tsx:27 — fade の effect が `onDone` を依存に持ち、App が毎回新しい関数を渡すのでフェード中の再描画でタイマーが張り直される。→ **反映**: 最新の onDone を ref に持ち、タイマーは fading が true になった 1 回だけ。
3. App.tsx:44 — 表紙の間も裏の DOM がそのままで、Tab / VoiceOver / ホイールが表紙を飛び越える。→ **反映**: Splash を main の外に出し、表紙の間は `main` に `inert`。表紙は `touch-none`（指のスクロールを裏に通さない）。ホイールは残る（2 秒なので許容）。
4. Splash.tsx:38 — img が長押し・ドラッグできるので「画像を保存」のシートやドラッグ像が出る。→ **反映**: img を `pointer-events-none`、`draggable={false}`、button を `select-none`。
5. Splash.tsx:39 — span のクラスの並びが CLAUDE.md の順（色は文字の後）に反する。→ **反映**。
6. ADR 021 — 「作り方は devlog」だがスクリプトが残っていない。→ **反映**: `scripts/make-splash.mjs` としてリポジトリに置く。
7. Splash.tsx:4 — `SPLASH_SRC` の export が使われていない。→ **反映**: モジュール内の const に。

## Codex `codex exec`（read-only、medium。P1 なし、P2 2 件、P3 1 件）
