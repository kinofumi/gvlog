# レビュー: 素材一覧の「この素材を編集する」ボタンと、スライダーの 0.1 秒刻みの矢印（2026-11-14）

ブランチ: `edit-button-and-step-arrows`。利用者の要望 2 件。

1. 素材をタップすると下に設定が出る仕組みが気づかれにくい → 各素材に「この素材を編集する」（開いている間は「編集を閉じる」）のボタン。
2. 尺のスライダーが指だと細かく合わせにくい → スライダーの両側に ◀ ▶。0.1 秒刻み（`frameStep.ts`、テストファースト）。FrameSlider は共用なので、つなぎの長さ・開始位置・終了位置にも付く。
